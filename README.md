# 镜策 · AI 创作工作台

镜策是在本机运行的中文 AI 图片、视频、语音和文字创作工具。它提供创作画布、素材库、图片生成、视频生成、MiniMax 配音、生成结果管理、语言模型对话和本机视频合成。

此仓库版本从程序源码白名单打包，适合先放入 GitHub 私有仓库。每位使用者配置自己的模型账号和 API Key；程序首次运行时创建独立的 `runtime/` 目录。

> **不可商用**：仅限非商业用途，修改版与再分发版本同样须遵守此限制。第三方组件遵循各自许可。

## 下载和启动

1. 安装 [Node.js 22.22 或更新版本](https://nodejs.org/)。
2. 从 GitHub 的 **Code → Download ZIP** 下载源码并完整解压，或克隆仓库。
3. 首次运行或更新依赖后，在源码目录执行 `npm ci --omit=dev`。
4. Windows 用户双击根目录的 `启动工作台.cmd`；其他系统在源码目录执行 `npm start`。
5. 浏览器打开启动窗口显示的地址。默认使用 [http://127.0.0.1:18970](http://127.0.0.1:18970)，端口被其他实例占用时自动选择空闲端口。启动入口只复用同一数据目录的实例。保留启动窗口，结束服务后再备份或更新数据。

程序使用 Node.js 内置 SQLite、bcryptjs 和 Nodemailer，以及随附的前端文件。依赖版本由 `package-lock.json` 固定。未配置模型连接时，可以编辑画布、管理素材和导入导出工程。模型调用需要联网，费用由相应平台收取。

源码包需要本机安装 Node.js。若要提供免安装 Node.js 的 Windows 版本，可通过 `tools/package-share.ps1` 构建包含运行环境的分享包，再放入仓库的 **Releases**。

## 模型服务商与 API 地址

| 功能 | 服务商网站 / 说明 | 镜策使用的 Base URL | 配置入口 |
| --- | --- | --- | --- |
| 新版视频 | [北北海视频平台](https://direct.beibeihai.xyz) | `https://sub.beibeihai.xyz` 或 `https://direct.beibeihai.xyz` | 连接中心 |
| 图片 | [北北海平台](https://sub.beibeihai.xyz) · [价格与接口说明](https://sub.beibeihai.xyz/pricing) | `https://sub.beibeihai.xyz` | 连接中心 |
| 文本 / 语言模型 | [北北海平台](https://sub.beibeihai.xyz) · [价格与接口说明](https://sub.beibeihai.xyz/pricing) | `https://sub.beibeihai.xyz/v1` | 连接中心 |
| 语音 | [MiniMax 官方接口与价格](https://platform.minimaxi.com/docs/guides/pricing-paygo) | `https://api.minimax.cn`（国内）或 `https://api.minimax.io`（国际） | 连接中心 → 添加接口 → 语音模型 |

在连接中心添加图片、视频、语言或语音模型接口，填写令牌后读取模型或验证连接，勾选模型并保存。语音模型目录来自 MiniMax 官方型号清单；读取音色用于检查令牌，不会生成配音。编辑已有接口时留空令牌会保留原密钥；删除接口须确认，工程、素材和生成记录保留。镜策目前支持上述平台的适配器，接入其他平台需要修改适配器代码。网址相同也不代表图片和文本具有相同模型权限。

语音生成支持 MP3、WAV、音色、语速、音量、音调和情绪设置。点击“生成配音”才会提交可能收费的合成任务。MiniMax 国内官方价格页当前列出 `speech-2.8-hd` 为 3.50 元/万计费字符、`speech-2.8-turbo` 为 2.00 元/万计费字符；页面说明一个汉字计 2 个字符。界面会估算国内基础价格，实际权限、用量和扣费以 MiniMax 账户与账单为准。国际接口使用美元报价，镜策不换算成人民币估价。

语音页的“新建音色”支持两种流程：上传 MP3、M4A 或 WAV 录音复刻，以及用文字描述设计音色。录音需为 10 秒至 5 分钟、不超过 20 MB；选择文件只保存并校验本机录音，点击“创建”后才上传 MiniMax。复刻试听文案最多 1000 字符（可留空），文字设计试听文案最多 500 字符（必填）。音色创建后可试听、下载预览、复制 Voice ID，并点击“使用此音色”回到配音页。

音色与当前语音账户关联，沿用连接中心的服务端令牌。创建任务可连续提交，刷新后找回原任务；创建响应中断时只允许核对平台记录，创建成功但试听下载或本地保存失败时只保存已有结果。镜策不会自动再次创建音色。录音保存在 `runtime/voice-recordings`，任务结果及连接快照保存在 `runtime/voice-results`、`runtime/voice-task-connections`，不包含在分享包内。

MiniMax 官方文档（2026-10-13 核对）说明：新创建的复刻及设计音色是临时音色，须在 7 天内用于正式语音合成才会长期保留；仅保存本地 ID 不会延长平台有效期。国内官方刊例价的复刻及设计音色首次正式使用费均为 9.90 元/个，创建时的试听另按实际字符用量计费；官方国内文字设计试听单价为 2.00 元/万计费字符，录音复刻试听按所选语音模型单价估算，实际扣费以账户账单为准。接口字段和规则见 [官方复刻文档](https://platform.minimaxi.com/docs/api-reference/voice-cloning-clone)、[官方设计文档](https://platform.minimaxi.com/docs/api-reference/voice-design-design) 和 [官方录音上传文档](https://platform.minimaxi.com/docs/api-reference/file-management-upload)。

图片和视频目录每分钟刷新，并在提交前再次核对。参数选项随模型能力联动；不支持的参考素材类型或超过数量限制会拦截提交。平台未提供的能力字段显示为“系统默认”，可以在“模型能力”中补充，平台后来公开的值优先。个人能力补充保存在本机 `runtime/model-capabilities.json`，更新程序时保留，干净发布包不携带该文件。

详细请求路径、图片模型列表、视频模型 ID 和配置示例见 [模型连接地址](docs/模型连接地址.md)。可选的腾讯云 COS 存储从界面另行配置，服务入口为 [腾讯云 COS](https://cloud.tencent.com/product/cos)。

## 使用流程

1. 新建工程，在创作画布中组织文字、图片、视频和素材卡。
2. 通过“语言模型”或 AI 文字卡编写内容，审阅并编辑草稿。
3. 填写对应平台的 API Key，刷新目录，选择自己的账号可用的模型。
4. 编辑提示词、参数和参考素材，确认后提交图片或视频生成。
5. 在生成结果中选择候选、下载或放回画布作为后续参考。
6. 本机视频合成需要自行准备 FFmpeg 和 ffprobe；本项目不提供下载安装脚本。

素材库和生成结果按工程分组，支持工程、类型和时间筛选。两个页面分别提供多选、全选当前列表、原文件 ZIP 下载、批量放到所属工程画布、删除与恢复。批量放置跳过已有素材卡并避让，保留当前工程和输入草稿；操作失败的项目保留选择，便于重试。

参考素材需要平台可访问的 HTTPS 地址或相应接口支持的上传方式。本机磁盘路径本身不能作为远程模型可读取的参考网址。

## 导出工程给朋友

打开要分享的工程，在创作画布右上角点击“导出工程包”，得到 `工程名称.miraframe.zip`。把这个文件发给朋友，朋友在幻帧的项目总览或画布点击“导入工程”，选择 ZIP 文件即可继续编辑，无需先解压。

工程包保留画布卡片、位置、分组、连线、文字、提示词、模型参数和素材选择，并包含该工程全部未删除的图片、视频、音频，以及卡片使用的技能和 AI 创作卡的回复图片。导入创建独立的新工程，素材与技能分配新编号，重复导入也不会覆盖已有工程。朋友使用自己的模型连接继续生成；导入、导出不会提交生成请求。

工程包不包含 API Key、账号连接、云存储密钥、生成任务记录及其他工程的数据。正在生成但尚未保存的结果不会进入本次包，保存完成后可再导出。单个工程包最大 1 GB；图片、音频、视频的单文件限制分别为 20 MB、100 MB、300 MB。导入前校验文件清单与素材完整性，失败时不保留半份工程。

旧版工程 JSON 备份仍支持导入，JSON 不包含媒体文件，需要重新上传素材。

## Blender 镜头预演

左侧“Blender 预演”支持故事 → AI 场景配置 → 用户编辑确认 → Blender 白模/运镜 → PNG → 验证 MP4 → 素材库。可替换场景、人物代理、道具和镜头路线，支持下载工程、关键帧、俯视路线图，并把预演作为后续视频模型参考。看完结果可在本页“对话修改”，让语言模型带着原场景和连续反馈生成修订方案，确认应用后再预演；支持恢复之前的场景版本。详见 [Blender预演工作流](docs/Blender预演工作流.md)。

本机版可直接调用已安装 Blender；HTTPS 网站通过下载的 Windows 本机助手调用用户电脑上的 Blender。助手首次连接须在本机授权当前网站，后续操作、进度和结果保存均在网站完成。助手首次启动自动准备 Node.js 和 MP4 编码工具，无需用户安装 Python；浏览器如询问本地网络访问，请允许。不会执行导入技能脚本或 AI 输出代码。

## 技能库与对话图片

左侧“技能库”支持导入 `SKILL.md`、Markdown、技能文件夹和 ZIP，以及新建、编辑、导出和删除恢复。AI 创作卡、画布语言模型侧栏和创作助手均可选择技能，加载文字规则与参考资料；脚本和工具依赖会保留并列出，不会自动执行。

AI 创作卡的要求、结果及上游文字不再按本机字符数截断，模型本身的上下文和输出限制仍适用。接口实际返回的图片可以预览、加入素材库、下载或拖放到画布。图片能力取决于所选模型，验证使用模拟响应，不代表账号已经具备生图权限。操作与兼容范围见 [技能库与对话图片](docs/技能库与对话图片.md)。

## 保存数据

工程、素材、任务记录和私有连接配置保存在 `runtime/`。备份时先停止工作台，再复制该目录；更新源码时保留原有 `runtime/`。

仓库的 `.gitignore` 忽略 `runtime/`、私有配置、密钥文件、日志、构建产物和本地压缩包。生成全新的可分发源码包时，使用白名单脚本 `tools/package-github.ps1`；生成 Windows 分享包时，使用 `tools/package-share.ps1`。

## GitHub 仓库和网站

[GitHub 发布指南](docs/GitHub发布指南.md) 提供私有仓库上传、邀请使用者、Releases 和后续更新步骤。

本版本包含 Node.js 后端，默认监听 `127.0.0.1`。服务器模式通过 `JINGCE_MULTI_USER=1` 启用账号登录、数据隔离、管理后台和个人中心；邮箱与密码共用配置的 Pictora 用户表，本站权限、会话、工程与管理数据独立。云存储由管理员统一配置，用户保留各自的模型 API 连接。个人中心支持任务与费用记录、公告、密码修改及设备管理，详见 [管理后台与个人中心](docs/管理后台与个人中心.md)。

GitHub 用于保存和分发源码；完整工作台需要部署后端，不能仅通过 GitHub Pages 运行。部署过程见 [服务器部署与同步](docs/服务器部署与同步.md)。
