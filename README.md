# 镜策 · AI 创作工作台

镜策是在本机运行的中文 AI 图片、视频和文字创作工具。它提供创作画布、素材库、图片生成、视频生成、生成结果管理、语言模型对话和本机视频合成。

此仓库版本从程序源码白名单打包，适合先放入 GitHub 私有仓库。每位使用者配置自己的模型账号和 API Key；程序首次运行时创建独立的 `runtime/` 目录。

> **不可商用**：仅限非商业用途，修改版与再分发版本同样须遵守此限制。第三方组件遵循各自许可。

## 下载和启动

1. 安装 [Node.js 20 或更新版本](https://nodejs.org/)。
2. 从 GitHub 的 **Code → Download ZIP** 下载源码并完整解压，或克隆仓库。
3. Windows 用户双击根目录的 `启动工作台.cmd`；其他系统在源码目录执行 `npm start`。
4. 浏览器打开启动窗口显示的地址。默认使用 [http://127.0.0.1:18970](http://127.0.0.1:18970)，端口被其他实例占用时自动选择空闲端口。启动入口只复用同一数据目录的实例。保留启动窗口，结束服务后再备份或更新数据。

程序只使用 Node.js 标准库和随附的前端文件，无需执行 `npm install`。未配置模型连接时，可以编辑画布、管理素材和导入导出工程。模型调用需要联网，费用由相应平台收取。

源码包需要本机安装 Node.js。若要提供免安装 Node.js 的 Windows 版本，可通过 `tools/package-share.ps1` 构建包含运行环境的分享包，再放入仓库的 **Releases**。

## 模型服务商与 API 地址

| 功能 | 服务商网站 / 说明 | 镜策使用的 Base URL | 配置入口 |
| --- | --- | --- | --- |
| 新版视频 | [北北海视频平台](https://direct.beibeihai.xyz) | `https://direct.beibeihai.xyz` | 左侧“视频模型连接” |
| 图片 | [北北海平台](https://sub.beibeihai.xyz) · [价格与接口说明](https://sub.beibeihai.xyz/pricing) | `https://sub.beibeihai.xyz` | 左侧“生图连接” |
| 文本 / 语言模型 | [北北海平台](https://sub.beibeihai.xyz) · [价格与接口说明](https://sub.beibeihai.xyz/pricing) | `https://sub.beibeihai.xyz/v1` | 左侧“语言模型” |

在“API 管理”中添加图片、视频或语言模型接口，填写令牌后点击“读取此令牌的模型”，勾选模型并保存。编辑已有接口时留空令牌会保留原密钥；删除接口须确认，工程、素材和生成记录保留。镜策目前支持上述平台的适配器，接入其他平台需要修改适配器代码。网址相同也不代表图片和文本具有相同模型权限。

图片和视频目录每分钟刷新，并在提交前再次核对。参数选项随模型能力联动；不支持的参考素材类型或超过数量限制会拦截提交。平台未提供的能力字段显示为“系统默认”，可以在“模型能力”中补充，平台后来公开的值优先。个人能力补充保存在本机 `runtime/model-capabilities.json`，更新程序时保留，干净发布包不携带该文件。

详细请求路径、图片模型列表、视频模型 ID 和配置示例见 [模型连接地址](docs/模型连接地址.md)。可选的腾讯云 COS 存储从界面另行配置，服务入口为 [腾讯云 COS](https://cloud.tencent.com/product/cos)。

## 使用流程

1. 新建工程，在创作画布中组织文字、图片、视频和素材卡。
2. 通过“语言模型”或 AI 文字卡编写内容，审阅并编辑草稿。
3. 填写对应平台的 API Key，刷新目录，选择自己的账号可用的模型。
4. 编辑提示词、参数和参考素材，确认后提交图片或视频生成。
5. 在生成结果中选择候选、下载或放回画布作为后续参考。
6. 本机视频合成需要自行准备 FFmpeg 和 ffprobe；本项目不提供下载安装脚本。

素材库和生成结果按工程分组，支持工程、类型和时间筛选。两个页面分别提供多选、全选当前列表、原文件 ZIP 下载、批量放到所属工程画布、删除与恢复。批量放置跳过已有素材卡并避让，保留当前工程和输入草稿；操作失败的项目保留选择，便于重试。

参考素材需要平台可访问的 HTTPS 地址或相应接口支持的上传方式。本机磁盘路径本身不能作为远程模型可读取的参考网址。

## 技能库与对话图片

左侧“技能库”支持导入 `SKILL.md`、Markdown、技能文件夹和 ZIP，以及新建、编辑、导出和删除恢复。AI 创作卡、画布语言模型侧栏和创作助手均可选择技能，加载文字规则与参考资料；脚本和工具依赖会保留并列出，不会自动执行。

AI 创作卡的要求、结果及上游文字不再按本机字符数截断，模型本身的上下文和输出限制仍适用。接口实际返回的图片可以预览、加入素材库、下载或拖放到画布。图片能力取决于所选模型，验证使用模拟响应，不代表账号已经具备生图权限。操作与兼容范围见 [技能库与对话图片](docs/技能库与对话图片.md)。

## 保存数据

工程、素材、任务记录和私有连接配置保存在 `runtime/`。备份时先停止工作台，再复制该目录；更新源码时保留原有 `runtime/`。

仓库的 `.gitignore` 忽略 `runtime/`、私有配置、密钥文件、日志、构建产物和本地压缩包。生成全新的可分发源码包时，使用白名单脚本 `tools/package-github.ps1`；生成 Windows 分享包时，使用 `tools/package-share.ps1`。
