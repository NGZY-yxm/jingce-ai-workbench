# 视频参数校验与错误诊断

修复日期：2026-10-14。

## 参数来源

视频模型目录中的 ID 仅证明当前连接能读取该模型，不代表它支持任意时长和分辨率。工作台不再自动生成 1–15 秒及 480p/720p/1080p 的通用组合，也不会把报价档位当成模型能力。

每个分辨率的生成时长按以下顺序确定：平台明确公布的数据、用户为当前模型补充的参数、用户已保存的系列补充。没有依据的字段显示“待确认”；画布、视频生成页和后端都会拦截对应提交，后台不会上传素材或创建生成任务。

在“视频生成 → 查看 / 补充模型能力”中可以填入服务商明确支持的参数。先填写分辨率，界面会增加该分辨率的时长输入框。示例 `720p`、`5,10` 只用于说明填写方法，不表示任何真实模型一定支持这些值。平台后来提供明确参数时，平台数据优先。

## 错误详情

任务记录保留平台 HTTP 状态、错误码、错误字段、平台响应请求编号、本次请求编号、响应格式和经过脱敏的错误文本。支持结构化错误、嵌套错误、字符串 error、msg、字段校验列表和纯文本响应。HTML 仅提取标题；空响应明确提示平台没有提供具体说明，不猜测失败原因。

错误文本中的当前 API Key、Bearer 凭证、常见密钥格式和 URL 查询参数会被隐藏。任务记录不保存原始响应正文。此前只记录了 HTTP 400 的旧任务无法补回当时已经丢失的响应内容。

已有平台任务继续按原编号查询；网络中断、5xx 和提交结果不确定的任务不会自动重复提交。修复不包含任何真实收费生成测试。
