# 技能库与对话图片

## 导入和使用技能

左侧的“技能库”支持新建技能、导入单个 Markdown 文件、技能文件夹或 ZIP。文件夹和 ZIP 中以 `SKILL.md` 识别技能，一个包中可以包含多个技能。导入前会显示名称、说明、正文和依赖信息；确认后保存到本机。

技能正文、说明、许可和文字参考资料可以编辑。删除为可恢复删除，在“已删除技能”中选择技能后恢复。导出 ZIP 保留正文、参考资料和随包导入的脚本、图片等附件。私有配置文件及 `.git`、`node_modules` 不会导入。

AI 创作卡、展开画布内的“语言模型”侧栏、独立“创作助手”都提供“使用技能”选项。AI 创作卡按卡片保存技能编号；两个聊天入口使用同一段对话，并在当前浏览器中按工程保存技能选择。切换技能影响后续请求，历史回复保持原样。所选技能已删除或未导入时会明确显示，请恢复或重新选择后再运行。

本版本使用技能中的文字规则和文字参考资料。AI 创作卡与对话将它们加入模型的系统消息；图片和视频生成将它们合并到本次生成提示词中。脚本、二进制附件、MCP 工具和需要其他应用操作的步骤不会自动执行；附件会保留供导出，界面会列出外部依赖。导入技能不会新增模型连接、发起图片或视频生成。

## 图片和视频生成使用技能

图片生成页、视频生成项、画布生图卡、画布视频卡以及原图片弹窗均提供“使用技能”下拉框。先在“技能库”导入或新建技能，再选择技能并填写本次图片或视频要求，点击原生成按钮提交。技能下拉框旁的按钮可直接打开技能库。选择“不使用技能”恢复原提示词生成。

图片生成页按当前浏览器和工程记住技能选择，刷新后恢复。画布生图卡按卡片保存技能编号；视频项与对应画布视频卡共享选择。工程导入导出保留卡片和视频项的技能编号，其他电脑需要单独导入对应技能；缺失或已删除的技能会显示提示，请重新选择或恢复后再生成。

提交时完整合并技能正文、文字参考资料和本次生成要求，不自动调用语言模型改写提示词。规则合并后沿用工作台现有 4000 字符上限，超限会在图片或视频提交前拒绝，不截断技能，不自动改用无技能生成。技能内的脚本、二进制附件与外部工具不会执行；图片和视频参考仍须通过现有参考素材入口选择。

每个任务保存实际提交的合并提示词、技能名称、编号和版本时间。修改或删除技能仅影响之后的新生成，已记录任务使用原快照，核对原操作编号不会再次提交。原始提示词保持可编辑，生成结果继续保存到素材库。

## AI 创作卡的长文本

AI 创作卡的具体要求、当前结果及文字上游输入已取消工作台原有的字符截断。保存、重新打开和工程导入导出都保留完整文字。卡片名称、模型编号等短字段仍按其用途校验；图片和视频接口原有的提示词约束单独适用。

取消本机字符限制不改变模型的上下文窗口、最大输出 token 或服务商限制。超出所选模型容量时，接口仍可能拒绝请求或返回截断结果。工作台不自动重发模型请求。

## 对话图片

“语言模型”和“创作助手”使用同一个聊天组件。模型通过 Chat Completions 返回的 HTTPS Markdown 图片、结构化图片内容、`message.images`，以及 PNG、JPEG、WebP 的 Base64 图片会显示为图片结果。AI 创作卡也保留图片结果，包括没有文字的纯图片回复。

每张图片提供“加入素材库”“放到画布”和下载操作。“放到画布”会先加入当前工程的素材库，再创建素材卡。展开画布并打开语言模型侧栏后，也可以直接将回复图片拖到画布。重复导入同一回复图片复用已有素材；保存到素材库后使用本机文件，不再依赖原外部链接。

图片记录位于 `runtime/text-results/`，素材文件位于 `runtime/assets/`。当前对话历史与技能选择保存在浏览器的本机存储，换浏览器或清理存储后不会自动恢复聊天。备份时同时保留原浏览器配置和整个 `runtime/`。

外部图片下载失败时可以重新加载或再次保存图片，只重试原图片的下载，不重新调用模型。超过 20 MB、非支持图片格式和本机或私有网络地址会拒绝下载。

图片结果取决于模型及接口实际返回的内容。导入一个生图技能不能让仅输出文字的模型自动产生图片，也不能代替现有图片生成接口。所有真实模型调用仍可能产生平台费用。

## 验证范围

自动化测试使用临时工程和模拟模型响应，检查技能导入、导出、应用、删除恢复，长文本保存和图片解析、预览及素材入库。浏览器验证覆盖三个选择入口、图片拖放、纯图片结果、页面刷新和桌面及手机宽度。图片和视频技能检查还覆盖原始提示词保留、实际请求合并、批量快照、原操作编号去重、缺失或已删除技能拦截、长度超限和取消选择，以及桌面和手机布局。验证不调用用户账号进行付费图片、视频或文字生成。
