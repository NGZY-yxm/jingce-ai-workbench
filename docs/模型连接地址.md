# 模型服务商网站和 API 接口地址

核对日期：2026-10-11。下列地址和请求路径取自当前程序的适配器代码，不含账号或密钥。发布准备时，视频平台首页和图片平台价格页返回 HTTP 200；此次没有提交收费生成请求。

## 服务入口

| 功能 | 网站 / 说明 | Base URL | 本地配置文件 |
| --- | --- | --- | --- |
| 新版视频 | [https://sub.beibeihai.xyz](https://sub.beibeihai.xyz) / [https://direct.beibeihai.xyz](https://direct.beibeihai.xyz) | 默认 `https://sub.beibeihai.xyz`，可选 `https://direct.beibeihai.xyz` | `runtime/connection.private.json` |
| 图片 | [https://sub.beibeihai.xyz](https://sub.beibeihai.xyz) · [价格与接口说明](https://sub.beibeihai.xyz/pricing) | `https://sub.beibeihai.xyz` | `runtime/image-connection.private.json` |
| 文本 / 语言模型 | [https://sub.beibeihai.xyz](https://sub.beibeihai.xyz) · [价格与接口说明](https://sub.beibeihai.xyz/pricing) | `https://sub.beibeihai.xyz/v1` | `runtime/text-connection.private.json` |
| 素材云存储（可选） | [腾讯云 COS](https://cloud.tencent.com/product/cos) · [控制台](https://console.cloud.tencent.com/cos) | 根据使用者自己的区域和存储桶配置 | `runtime/storage.private.json` |

上述 `*.private.json` 文件由工作台在本机保存，整个 `runtime/` 都不应进入仓库。图片、视频和文本连接分开保存，使用者需要分别检查账号、密钥和权限。

## 当前程序调用的请求路径

下表列出适配器已有的调用路径，供查阅和排查配置。GET 模型目录需要密钥时，使用相应账号授权；生成用 POST 会产生平台请求，费用以平台规则和账单为准。

| 功能 | 方法 | 完整地址 / 路径模板 |
| --- | --- | --- |
| 视频模型目录 / 只读验证 | GET | `{视频 Base URL}/v1/models` |
| 提交新版视频任务 | POST | `{视频 Base URL}/api/v3/contents/generations/tasks` |
| 查询新版视频任务 | GET | `{视频 Base URL}/api/v3/contents/generations/tasks/{taskId}` |
| 图片公开模型广场 | GET | `https://sub.beibeihai.xyz/api/v1/model-plaza` |
| OpenAI 兼容图片模型目录 / 检查 | GET | `https://sub.beibeihai.xyz/v1/models` |
| OpenAI 兼容图片生成 | POST | `https://sub.beibeihai.xyz/v1/images/generations` |
| OpenAI 兼容图片参考 / 编辑 | POST | `https://sub.beibeihai.xyz/v1/images/edits` |
| Gemini 图片模型目录 / 检查 | GET | `https://sub.beibeihai.xyz/v1beta/models` |
| Gemini 图片生成 | POST | `https://sub.beibeihai.xyz/v1beta/models/{model}:generateContent` |
| 文本模型目录 / 只读验证 | GET | `https://sub.beibeihai.xyz/v1/models` |
| 文本多轮对话 | POST | `https://sub.beibeihai.xyz/v1/chat/completions` |

视频和 OpenAI 兼容请求由后端添加 `Authorization: Bearer <自己的 API Key>`。Gemini 图片请求使用 `x-goog-api-key`。在工作台界面保存密钥即可，使用者不需要把请求头写入仓库。

图片 Base URL 不带 `/v1`，文本 Base URL 带 `/v1`。当前适配器会补齐相应请求路径；不要将完整的 `/chat/completions` 或图片生成路径填成 Base URL。

## 模型选择

新版视频适配器当前识别以下完整模型 ID，最终只显示当前密钥查询结果中能匹配的条目：

- `seedance-2.0-933-720P（秒）`
- `seedance-2.0-fast-933-720P（次）`
- `seedance-2.0-mini-903-720P（次）`
- `seedance-2.5-301010-1K（秒）`
- `minimax-h3-933-2K（次）`

图片适配器的默认候选模型包括：

- `gpt-image-2.5-flare`
- `gpt-image-2.5-sunburst`
- `image-2`
- `grok-imagine-image`
- `grok-imagine-image-2.0`
- `gemini-nano-banana-2.1`
- `gemini-3.1-flash-image-preview`
- `gemini-3-pro-image`

候选列表表示程序已有对应适配，不保证每个账号都能调用。文本连接没有内置固定模型清单，先填写自己的文本 API Key，再点击“刷新语言模型”，从当前目录选择模型。目录可见和实际文字生成成功需要分别验证。

新版视频文档目前没有返回固定报价，程序显示费用待平台确认。图片报价按公开目录和账号分组展示，最终收费仍以自己的平台账单为准。

## 旧视频连接

`https://api.beibeihai.xyz` 是历史视频平台地址，旧价格页为 [https://api.beibeihai.xyz/pricing](https://api.beibeihai.xyz/pricing)。程序保留旧适配器，以便恢复和查询已有旧任务。新使用者配置上表的新版视频地址。

## 配置示例与公开范围

[连接配置示例.json](连接配置示例.json) 用于说明三种连接的 Base URL，所有密钥字段均为空。它不会由程序自动加载；正式使用时通过界面保存自己的连接。

服务商网址、Base URL、接口路径、模型 ID 和无密钥示例可以放进说明文档。个人 API Key、腾讯云 SecretId / SecretKey、私有工程、付费任务记录和带鉴权参数的素材链接保存在本地。

私有 GitHub 仓库中的本说明只有获得仓库访问权的人能看到。如果希望外部访问者只查看这些网址，可另建公开介绍页或公开文档仓库，复制本说明中的服务入口和接口地址即可。
