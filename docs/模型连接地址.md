候选列表表示程序已有对应适配，不保证每个账号都能调用。文本连接没有内置固定模型清单，先填写自己的文本 API Key，再点击“刷新语言模型”，从当前目录选择模型。目录可见和实际文字生成成功需要分别验证。

MiniMax 语音接口在连接中心选择“语音模型”类型。语音候选来自程序已接入的官方型号，不代表账户已开通权限；“读取此令牌的模型”和“验证令牌”使用只读音色接口 `/v1/get_voice` 确认连通性，不会提交收费配音。当前候选型号为 `speech-2.8-hd`、`speech-2.8-turbo`、`speech-2.6-hd`、`speech-2.6-turbo`、`speech-02-hd` 和 `speech-02-turbo`。

国内同步语音价格页当前列出 `speech-2.8-hd` 为 3.50 元/万计费字符、`speech-2.8-turbo` 为 2.00 元/万计费字符。平台说明一个汉字计 2 个字符，英文字母、标点、空格和换行各计 1 个字符。界面预估按此基础价格计算；音色属性、实际账户权限、用量与最终扣费以 MiniMax 平台为准。国际价格以美元计，工作台不换算成人民币估价。

工作台每分钟同步新版视频的当前密钥目录及模型广场公开报价，生成前再次读取最新数据。按秒模型的预估费用按视频秒数计算，按次模型按任务数量计算；报价单位为人民币。已提交的任务保留提交时的报价和参数，不随后续价格更新改写。如果生成前发现报价变化，工作台要求刷新并核对费用。

平台结构化报价有分辨率区间时，仅提供其列出的档位；未提供逐模型时长范围、分辨率列表或运行耗时预期时，界面明确注明未公开，保留通用接口参数供选择，实际支持以平台响应为准。不同公开分组价格冲突或报价读取失败时，费用显示待确认，不将缺失价格当作免费。图片和视频的公开报价作为预估，最终收费仍以自己的平台账单为准。

### 页面内创建自定义音色

在“语音生成 → 新建音色”选择“上传录音复刻”或“文字设计音色”，使用当前模型绑定的 MiniMax 连接。复刻录音仅支持 MP3、M4A、WAV，10 秒至 5 分钟，最大 20 MB；服务端读取文件结构校验时长，无需本机 FFmpeg。原录音可在页面试听，点击创建后才以 multipart 上传官方接口，再发送 `file_id`、`voice_id` 和可选试听字段。平台 int64 文件编号保持精确，不以 JavaScript 浮点数四舍五入。

文字设计发送官方 `prompt`、`preview_text`、`voice_id`；试听从 `trial_audio` 的十六进制音频保存。设计接口不发送 `model` 字段，后续正式配音使用配音页选择的模型。镜策单次音色描述限制为 2000 字符；设计试听最多 500 字符且必填，复刻试听最多 1000 字符且可留空。Voice ID 为 8–256 位，以英文字母开头，仅含字母、数字、连字符或下划线，末尾不能为连字符或下划线。

创建任务单独保存，提交后可以继续创建。重放同一操作编号返回已有任务，不重新创建；返回成功的 Voice ID 与试听结果先保存到本机，再处理试听文件。下载失败时保留音色并提供“重试保存试听”，只读取已有音频。响应中断时转为“需核对平台”；“核对平台音色”仅调用 `/v1/get_voice`，列表未找到音色仍保留待核对状态。已保存的音色会加入当前账户的音色选择列表，点击“使用此音色”后再明确提交正式配音。

官方规则核对日期为 2026-10-13：复刻和设计音色创建时不收取音色费，试听按字符收费，首次正式合成时收取音色费；国内官方刊例价均为 9.90 元/个。两类音色初始为临时音色，7 天内完成首次正式合成后才长期保留。镜策中的名称、任务记录或本地 Voice ID 不能代替平台音色，也不会延长有效期。官方国内文字设计试听单价为 2.00 元/万计费字符，录音复刻试听按所选语音模型单价估算；录音复刻需要账户完成个人或企业认证。录音原件保存在本机，点击创建后会上传到所选 MiniMax 官方区域；实际权限、音色质量和扣费须用自己的账户验证。
