镜策 · AI 图片与视频创作工作台
Windows 10 / Windows 11 64 位分享版
2026-10-11 版，已接入新版视频 API
已修正切换视频模型时重置生成时长的问题。

一、安装和打开
1. 将收到的 ZIP 压缩包完整解压到一个普通文件夹，不要在压缩包内直接运行。
2. 双击“安装镜策.cmd”，程序会安装到你的用户目录，并创建桌面和开始菜单快捷方式。
   默认安装位置：%LOCALAPPDATA%\Programs\JingceStudio，无需管理员权限。
3. 双击桌面的“镜策工作台”打开；浏览器会自动显示工作台。
   请保留启动窗口。关闭启动窗口，或双击“停止工作台.cmd”，可以停止服务。
4. 也可以不安装，直接在解压后的文件夹中双击“启动工作台.cmd”。

运行环境已内置，不需要另外安装 Node.js，不需要执行 npm install。
默认本机地址为 http://127.0.0.1:18970；如果该端口已有其它程序，工作台会自动使用空闲端口。
打开的网址以启动窗口显示为准。程序只接受本机访问。

二、第一次使用
分享包不带任何人的工程、素材、生成记录、API Key 或云存储配置。
1. 点击“新建工程”，输入工程名称。
2. 要生成视频，在左侧“视频模型连接”中填写你自己的视频平台 API Key 并保存。
   当前视频地址：https://direct.beibeihai.xyz
   保存后刷新“当前 Key 模型目录”，选择自己的 Key 实际可用的完整模型名称。
   没有填写 Key，或目录查询失败时，不会把旧模型目录当作当前账号可用的模型。
3. 要生成图片，在左侧“生图连接”中填写你自己的生图平台 API Key 并保存。
   当前接入平台：https://sub.beibeihai.xyz
4. 要使用语言模型，在左侧“语言模型”中填写文本模型 API Key，刷新当前密钥可用的模型目录并保存；然后打开“语言模型”标签进行文字对话。
5. 在“创作画布”“素材库”“图片生成”“视频生成”“生成结果”中开展创作。
6. 使用图片、视频、音频作为视频参考时，按界面提示配置自己的素材云存储，或提供平台可访问的公网 HTTPS 参考链接。
   本机文件不能仅凭磁盘路径作为云端参考；音频上传支持 MP3 / WAV。
7. 新版视频接口支持的时长、分辨率和参考方式，以所选模型的参数提示为准。
   平台未返回价格时会显示“费用待平台确认”，请先在自己的平台账号中确认收费。

工作台本身不会附送平台账号、余额或模型额度。实际图片 / 视频生成需要联网，按模型平台规则计费。
图片、视频生成和下载功能可以直接使用。
如果要把多个片段在本机拼接成片，请双击“安装视频合成工具.cmd”。它会从 Gyan.dev 下载 FFmpeg，校验后安装到当前工作台的 runtime\tools，不修改系统 PATH；安装完成后重启工作台。
已安装的用户请从安装目录运行该脚本；免安装用户请从正在使用的解压目录运行。
FFmpeg 二进制不内置在 ZIP 中，只有本机合成需要另行下载。

三、数据保存和更新
工程、素材、生成任务与连接配置保存在程序目录旁的 runtime 文件夹中。
备份时可复制整个程序文件夹，或在完全停止工作台后单独备份 runtime。
重新安装会更新程序文件，保留已有 runtime 数据。更新前请停止当前安装目录中的工作台。
请不要把使用后的整个文件夹直接分享给别人，里面的 runtime 可能包含你的私有素材和密钥。
需要再次分发时，请使用原始干净 ZIP。

四、遇到问题
- 无法打开：确认 ZIP 已完整解压，且 bin\node.exe 存在；从“启动工作台.cmd”查看错误信息。
- 启动较慢：首次运行可能等待公开模型目录的网络查询。网络不可用时仍可进行本地工程编辑；视频生成需要填写自己的 Key 并成功读取当前 Key 的模型目录。
- 生成失败：确认自己的平台账号、API Key、余额、模型参数和参考素材均满足平台要求。
- 任务已受理：先查询现有任务状态，避免重复提交产生额外扣费。
- 不再使用：先停止工作台，再移除桌面 / 开始菜单快捷方式和安装文件夹。移除文件夹前请备份 runtime。
